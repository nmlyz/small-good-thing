small-good-thing is a tiny program that writes one line about a small good thing that happened today: a parcel left with a neighbour, brought back with a cake still warm from her oven — two slices already missing. The line is a single sentence, at most 200 characters, checked by the program before it is written.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). It needs no network, and writes the same bytes on every run.
