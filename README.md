small-good-thing is a tiny program that writes one line about a small good thing that happened today — a single sentence, at most 200 characters, built to make a reader smile.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
